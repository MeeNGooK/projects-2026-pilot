# portbear v2.0

`portbear`는 스티키 노트의 질감을 가진 모바일 지향 관계·지역 콘텐츠 파일럿입니다. 일반 이용자의 새로운 인연 탐색과 콘텐츠 소비, 그리고 자영업자의 긴급 재고·이용권 홍보 실험을 한 화면의 카드 흐름으로 다룹니다.

> 배포 주소: https://meengook.github.io/projects-2026-pilot/

## v2.0 주요 변경사항

가장 최근의 기본 소개팅 프로토타입 백업과 비교해, 아래 항목을 추가·개편했습니다.

### 경험과 인터랙션

- 카드형 화면을 모바일 전체 화면형 스티키 노트 UI로 전환했습니다.
- 키보드 방향키와 휴대폰 터치 스와이프를 모두 지원하며, 좌측은 콘텐츠, 우측은 새 인연으로 이동합니다.
- 다음 노트가 미리 겹쳐 보이지 않도록 하고, 선택한 방향에 맞춰 종이를 넘기는 전환 애니메이션을 적용했습니다.
- 시작 시 곰돌이 일러스트 1~5 프레임이 한 번의 터치 뒤 순서대로 벗겨지는 인트로를 추가했습니다.

### 계정과 프로필

- Firebase 이메일/비밀번호 로그인 및 회원가입 흐름을 추가했습니다.
- 회원가입에서 공개 프로필 항목 3개를 선택·입력할 수 있으며, 선택 해제와 입력 검증을 지원합니다.
- 가입 유형을 `베어`(일반 사용자, 기본값)와 `포터`(콘텐츠 제작자·자영업자)로 구분하고 Firestore 사용자 문서에 저장합니다.
- 마이페이지에는 표현 사진, 활동 지역, 관심사, 선호 여행지와 이용 유형 배지를 표시합니다.

### 관계와 커뮤니티

- Like는 개인 취향 기록으로, Hot은 상호 호감과 채팅 가능 여부를 위한 별도 반응으로 분리했습니다.
- Hot 목록과 상호 Hot 채팅 진입점을 하단 채팅 탭 및 마이페이지에서 확인할 수 있습니다.
- 댓글·좋아요·별점이 가능한 테스트용 콘텐츠 피드를 넣었습니다.
- 유효기간과 포인트를 가진 초대형 대화 공간(워크스페이스) 시뮬레이션을 추가했습니다.

### 지역 자영업자·예약 시뮬레이션

- 호텔 빈 객실, 영화관 빈 좌석 등 긴급 재고를 처리하는 광고·이용권 에셋을 추가했습니다.
- 콘텐츠의 책갈피 저장, 마이페이지의 북마크·예약 목록, QR 예약 확인 화면을 구현했습니다.
- AI 예약 대화에서 고객 정보 전달 → 예약 완료가 이어지는 테스트 흐름을 제공합니다.
- 사업자 발행, QR 사용, 재고 차감, 공정성 안내를 포함한 사회혁신 MVP 시운전 화면을 추가했습니다.

## 현재 데이터와 API 준비 상태

- 계정과 공개 프로필: Firebase Authentication / Firestore
- 데모 콘텐츠, 반응, 북마크, 예약, 포인트, 초대방: 현재 브라우저 `localStorage` 기반 시뮬레이션
- 실제 결제·예약 확정·지도·외부 사업자 API·콘텐츠 검수는 아직 연결하지 않았습니다.

## API 테스트 다음 단계

1. Firestore 컬렉션 설계: 사용자, 포터 사업자 프로필, 오퍼, 예약, Hot, 채팅방, 메시지
2. 예약 API 어댑터: 재고 조회 → 예약 요청 → 사업자 확인/취소 → QR 발급 상태를 분리
3. 권한 규칙: 본인 프로필·반응·대화방 접근과 포터의 오퍼 발행 권한을 Firestore Rules로 제한
4. 결제/포인트: 실제 결제 전에는 테스트 포인트 원장과 idempotency 키부터 적용
5. 지도: 장소 검색 및 위치 기반 오퍼 노출을 위해 지도 제공자 API를 별도 모듈로 연결

## 실행

정적 웹앱이므로 `sgt/index.html`을 로컬 정적 서버 또는 GitHub Pages에서 열면 됩니다. Firebase를 사용하는 경우 Firebase Console에 현재 배포 도메인을 Authentication 허용 도메인으로 등록해야 합니다.

## 프로젝트 구조

```text
sgt/
├─ index.html               # 앱 진입 화면
├─ app.js                   # 카드/스와이프/콘텐츠 상호작용
├─ firebase-auth.js         # Firebase 계정·프로필 연동
├─ meta-hub.js              # 마이페이지, Like·Hot·초대방
├─ pilot.js                 # 자영업자/사회혁신 시운전
└─ assets/                  # 인트로와 테스트 이미지
```
